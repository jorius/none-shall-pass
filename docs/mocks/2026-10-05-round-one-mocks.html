1 · Packet cards, v2: option C with coloured protocol chips

Each protocol has its own chip colour, so after a few waves you read GET / POST / SSH / SMTP / TCP at a glance. Red stays reserved for the target and the hints. Encoding is highlighted on every packet, always, for free (dotted cyan: %27, %20, +). It lights up real users' blue+wool+socks too, so it never gives an attack away by itself. Commas are left alone, since highlighting them would point at SQL. The red wavy underline is still the paid hint (H, ×0.75), shown here on the XSS card.
